[✨🚘] Make "Co hoří?" delightful

- Improve the visual design of the entire application.
- The application should look like a polished modern SaaS product.
- Keep the visual style professional but slightly playful.
- The core metaphor is that problems gradually start burning.
- Add smooth animations when:
    - a new item appears
    - a task is created
    - an item changes urgency
    - an item moves higher in the list
    - an item becomes overdue
    - an item is resolved
    - an item is deleted
    - a filter changes
    - onboarding generates the personalized checklist
- Items should smoothly reorder when their urgency changes.
- Add subtle visual progression:
    - V pohodě should feel calm
    - Začíná hořet should attract a little attention
    - Hoří should be clearly visible
    - HOŘÍ TO! can contain a tasteful animated fire effect
- Do not make the application look like a game.
- Critical items can have subtle animated fire, glow, heat or smoke effects.
- When the user resolves the last critical item, show a short celebration.
- For example:
    - fire disappears
    - dashboard becomes calm
    - small success animation
    - text `"Firma zatím nehoří 🎉"`
- Add good empty states.
- Add a nice onboarding transition.
- Make the application look great on:
    - desktop
    - tablet
    - mobile
- Respect `prefers-reduced-motion`.
- Animations should not affect usability.
- Animation logic should be reusable and not hardcoded independently in every component.
- Avoid unnecessary visual clutter.
- Do a final UI, accessibility and responsive-design review.
- Run all automated tests after the visual changes.
- Keep in mind the DRY principle.
- Do a proper analysis of the current functionality before implementing.
