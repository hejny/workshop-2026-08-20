[✨🦍] Automatically determine what is burning

- Add an urgency engine.
- The application should automatically determine which things currently require the most attention.
- Do not store calculated urgency directly.
    - Derive it from the underlying data.
- Each item should get an urgency score between 0 and 100.
- Take into account:
    - severity
    - deadline
    - whether the deadline has already passed
    - how many days remain
    - status
    - whether the item represents a legal or tax obligation
    - whether ignoring the item can create a fine, financial loss or operational problem
- Display a human-readable reason for the urgency.
- Examples:
    - `"Datová zpráva je 8 dní nepřečtená - blíží se fikce doručení."`
    - `"Registrace měla být provedena před 3 dny."`
    - `"Do deadline zbývá 1 den."`
    - `"Obrat se blíží hranici pro registraci k DPH."`
    - `"Faktura je 14 dní po splatnosti."`
    - `"Doména expiruje za 5 dní."`
- Automatically order the dashboard by urgency.
- Visually distinguish:
    - 🟢 V pohodě
    - 🟡 Začíná hořet
    - 🟠 Hoří
    - 🔥 HOŘÍ TO!
- Add a summary at the top:
    - Kolik věcí hoří
    - Kolik je po termínu
    - Kolik je potřeba řešit dnes
    - Kolik je potřeba řešit tento týden
    - Kolik věcí je hotových
- Add filters:
    - Všechno
    - Hoří
    - Dnes
    - Tento týden
    - Po termínu
    - Hotovo
- Allow filtering by category.
- Keep all urgency calculations, filtering and summary calculations outside React components.
- Write unit tests for the urgency engine.
- Cover boundary conditions and important edge cases.
- The tests should verify business behavior rather than implementation details.
- Do a proper analysis of the current functionality before implementing.
