[✨🐀] Make "Co hoří?" a real working tool

- Allow users to create their own items.
- Allow editing existing items.
- Allow deleting items.
- Ask for confirmation before deleting.
- Allow marking an item as resolved.
- Allow reopening a resolved item.
- Support:
    - one-time deadlines
    - recurring tasks
    - tasks without a specific deadline
    - conditional tasks that become relevant when something happens
- Example recurring tasks:
    - Zkontrolovat datovou schránku
    - Předat doklady účetní
    - Zkontrolovat neuhrazené faktury
    - Zkontrolovat zálohy
    - Zkontrolovat aktivní přístupy
- Example conditional tasks:
    - První zaměstnanec
    - První faktura do zahraničí
    - První nákup zahraniční SaaS služby
    - Překročení obratu pro DPH
    - Změna jednatele
    - Změna sídla společnosti
- Store all user data locally in the browser.
- Do not add a backend or database.
- Provide a clear distinction between:
    - predefined template item
    - automatically generated item
    - user-created item
- Allow the user to add a short note to any item.
- Allow adding a responsible person as simple text without implementing accounts or authentication.
- Keep the interface fast and simple.
- Keep in mind the DRY principle.
- Do a proper analysis of the current functionality before implementing.
